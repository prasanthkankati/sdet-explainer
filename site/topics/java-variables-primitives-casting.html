2.2 Variables, Primitive vs Reference Types & Type Casting

1. Definition

Java splits all data into 8 fixed-size raw primitive types that store numbers directly and reference variables that store Heap addresses; widening converts small to large automatically while narrowing needs an explicit cast.

2. Memory hook

8 primitives hold numbers directly; References hold Heap addresses. Small -> Big is free; Big -> Small needs (cast).

  • 8 primitives: byte (1B), short (2B), int (4B), long (8B), float (4B), double (8B), char (2B), boolean (true/false).
  • Default values apply ONLY to class/static fields: local variables inside methods have no defaults and must be assigned before reading.
  • Widening vs Narrowing: assigning int to long or double is safe and automatic; casting double to int chops off decimals.

3. Variable scopes & numeric widening chain

5. Code example: defaults, widening vs narrowing & Selenium casting

public class VariableCastingDemo {
    static int defaultRetries;        // static default = 0
    String baseUrl;                   // instance default = null

    public static void main(String[] args) {
        int rawSec = 5;
        long millis = rawSec * 1000L; // widening: int -> long (automatic, 1000L avoids overflow)
        double uiPrice = 499.95;
        int wholePrice = (int) uiPrice; // narrowing cast: drops .95 -> 499

        System.out.println("Default=" + defaultRetries + " Whole=" + wholePrice + " ms=" + millis);
    }
}

6. Execution flow, step by step

  1. Class loads and assigns defaultRetries = 0 before main starts.
  2. rawSec lives on main's Stack frame storing literal binary bits for 5.
  3. Multiplying by 1000L promotes the calculation to 64-bit long cleanly with no cast needed.
  4. Casting (int) uiPrice discards the .95 fraction instead of rounding, producing 499.
  5. Trying to print an uninitialized local int x; stops at compile time with variable x might not have been initialized.

8. Why it matters

Understanding primitive sizes and casting prevents silent integer truncation (such as 5 / 2 == 2 instead of 2.5) and ClassCastException bugs.

SDET link: Wait timeouts take long seconds or Duration, product prices parsed from QKart need double rather than int truncation, and casting WebDriver to TakesScreenshot checks the concrete object type at runtime.

9. Quick test

What is the value of int x = (int) 19.99;? 19 — narrowing truncates everything after the decimal point.
