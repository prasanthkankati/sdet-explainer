2.4 Operators, Control Flow & Loops

1. Definition

Short-circuit operators skip unnecessary right-hand checks when the result is already known, and loops walk fixed counts, element collections, or retry conditions with break/continue.

2. Memory hook

&& stops on first false, || stops on first true — & and | evaluate both sides.

  • Null-safe guard: if (el != null && el.isDisplayed()) skips el.isDisplayed() when el is null.
  • Choose the right loop: for (int i) when you need indexes, enhanced for (T x : list) when scanning items, while when waiting for a state.
  • Modern switch -> (Java 14+): arrow syntax returns values directly with zero accidental fall-through.

5. Code example: short-circuit safety, arrow switch & Selenium pagination

import java.util.List;

public class FlowControlDemo {
    static String browserUrl(String env) {
        return switch (env) {                             // Java 14+ switch expression (no break needed)
            case "prod" -> "https://www.selenium.dev/";
            case "qa"   -> "https://qkart-qa-web.labs.crio.do/";
            default     -> throw new IllegalArgumentException("Unknown env: " + env);
        };
    }

    public static void main(String[] args) {
        List<String> items = List.of("Shoe", "", "Watch");
        for (String item : items) {
            if (item == null || item.isBlank()) continue; // || short-circuits if null; skip blanks
            System.out.println("Found: " + item + " at " + browserUrl("qa"));
            if (item.equals("Shoe")) break;               // stop scanning once target is matched
        }
    }
}

6. Execution flow, step by step

  1. browserUrl("qa") matches "qa" and returns the QKart URL directly without checking default.
  2. The enhanced for loop pulls "Shoe", checks item == null || item.isBlank(), finds both false, and prints it.
  3. Because item.equals("Shoe") is true, break immediately exits the loop without visiting "Watch".
  4. Had an item been null, || evaluates left-to-right, sees true on item == null, and skips item.isBlank() so no NullPointerException occurs.
  5. continue would only skip the current element while letting the loop move to "Watch".

8. Why it matters

Short-circuit guards (&& / ||) prevent NullPointerException and ArrayIndexOutOfBoundsException in one expression.

SDET link: When looping through driver.findElements(By.cssSelector(".card")), break early once the matching QKart item is clicked, or use a while (hasNextPage) loop with a max-page safety cap so broken pagination never hangs CI forever.

9. Quick test

What is the difference between break and continue inside a loop? break exits the loop completely; continue skips only the rest of the current iteration.
