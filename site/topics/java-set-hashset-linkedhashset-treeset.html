5.3 Set: HashSet vs LinkedHashSet vs TreeSet

1. Definition

Set forbids duplicate items by returning false on repeated adds: HashSet gives fastest unordered O(1) checks, LinkedHashSet preserves insertion order, and TreeSet sorts elements via Comparable or Comparator.

2. Memory hook

No duplicates! HashSet = random fast; LinkedHashSet = insertion order (like window handles!); TreeSet = sorted (NO null!).

  • Secret inside HashSet: it is backed by an internal HashMap<E, Object> storing your item as key and a dummy constant PRESENT as value.
  • Order guarantees: HashSet (none), LinkedHashSet (predictable click/open order), TreeSet (sorted ascending order).
  • Null rule trap: HashSet & LinkedHashSet allow one null; TreeSet throws NullPointerException on null!

5. Code example: detecting duplicate IDs & tracking Selenium window handles

import java.util.*;

public class SetDemo {
    public static void main(String[] args) {
        List<String> scrapedSkus = List.of("QK-1", "QK-2", "QK-1", "QK-3");
        Set<String> seen = new LinkedHashSet<>(); // keeps exact first-seen order
        List<String> dupes = new ArrayList<>();

        for (String sku : scrapedSkus) {
            if (!seen.add(sku)) {                 // add() returns false if already inside Set!
                dupes.add(sku);
            }
        }
        Set<String> sorted = new TreeSet<>(seen); // alphabetically sorted copy
        System.out.println("Unique order: " + seen + " | Dupes: " + dupes + " | Sorted: " + sorted);
    }
}

6. Execution flow, step by step

  1. LinkedHashSet<String> seen records unique SKUs in the exact sequence scraped from the UI.
  2. When "QK-1" appears a second time, seen.add("QK-1") checks hash + equals, sees a match, and returns false.
  3. !seen.add(sku) traps that duplicate cleanly into dupes in a single O(n) pass.
  4. Passing seen into new TreeSet<>(seen) sorts all unique IDs automatically in O(n log n).
  5. Inserting null into sorted would fail immediately with NullPointerException because TreeSet must call compareTo.

8. Why it matters

Checking existence via hashSet.contains(x) takes O(1) constant time rather than scanning a 10,000-row ArrayList linearly.

SDET link: driver.getWindowHandles() returns a Set<String> (internally a LinkedHashSet in Selenium Java) so newly opened browser tabs preserve open order without duplicate window handles.

9. Quick test

What does TreeSet.add(null) do? Throws NullPointerException because null cannot be compared against other elements.
