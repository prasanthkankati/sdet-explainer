4.1 Class & Object

1. Definition

A class is a compile-time design rulebook taking zero object Heap space, while an object is a physical Heap memory block created at runtime bundling state fields and action methods.

2. Memory hook

Class = Blueprint template in Metaspace (0 instance RAM); Object = Real instance on Heap created via new.

  • One class, unlimited objects: call new LoginPage(driver) repeatedly and each gets its own isolated field block.
  • State vs Behavior: fields hold what an object knows (url, timeout); methods hold what it does (open(), clickLogin()).
  • == vs .equals(): == compares Stack memory addresses; .equals() checks logical equality if overridden.

5. Code example: creating independent objects vs aliasing references

class LoginPage {
    String url;                       // Heap field defaults to null
    void open() { System.out.println("Opening " + url); }
}

public class ObjectDemo {
    public static void main(String[] args) {
        LoginPage p1 = new LoginPage();           // allocates Heap object @A1
        p1.url = "https://qkart-qa-web.labs.crio.do/login";
        LoginPage p2 = new LoginPage();           // allocates Heap object @B2
        p2.url = "https://www.selenium.dev/";
        LoginPage p3 = p1;                        // alias: shares @A1 with p1

        System.out.println("p1==p2: " + (p1 == p2)); // false
        System.out.println("p1==p3: " + (p1 == p3)); // true
        p1.open();
    }
}

6. Execution flow, step by step

  1. new LoginPage() allocates an object at Heap address @A1 and clears its fields to null/0/false.
  2. p1.url = ... writes the QKart URL into @A1's field slot.
  3. The second new LoginPage() builds an independent object at @B2 referenced by p2.
  4. LoginPage p3 = p1 creates zero new Heap objects — it only copies address @A1 into p3.
  5. Calling driver.quit() later kills the browser session but leaves the Java ChromeDriver object on the Heap until GC runs (calling commands on it throws NoSuchSessionException, not NPE).

8. Why it matters

Bundling data and operations inside objects stops brittle global variables and powers every OOP pattern and Page Object framework.

SDET link: Every LoginPage login = new LoginPage(driver);, By.id(...), and WebElement handle in Selenium is a Heap object; forgetting to initialize the field causes the #1 QA error: NullPointerException.

9. Quick test

LoginPage a = new LoginPage(); LoginPage b = a; — How many Heap objects exist? 1 object with 2 Stack references pointing to it.
