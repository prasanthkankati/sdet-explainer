3.1 @DataProvider & Multi-Dimensional Object Arrays

Data-driven testing engine: Object[][] matrix mapping, Iterator streaming, Method reflection routing, and parallel data providers.

TestNG's @DataProvider annotation is the gold standard for data-driven testing in Java. It allows a single test method to execute repeatedly with different combinations of input arguments, producing distinct pass/fail status and test metrics for each data row.

1. The Object[][] Matrix Pattern

A data provider method must return an Object[][] (two-dimensional object array) or an Iterator<Object[]>. Each row in the matrix represents an individual test execution:

import org.testng.annotations.DataProvider;
import org.testng.annotations.Test;

public class DataProviderDemo {
    @DataProvider(name = "loginCredentials")
    public Object[][] provideCredentials() {
        return new Object[][] {
            {"standard_user", "secret_sauce", true},
            {"locked_out_user", "secret_sauce", false},
            {"problem_user", "secret_sauce", true}
        };
    }

    @Test(dataProvider = "loginCredentials")
    public void testUserAuthentication(String username, String password, boolean expectedSuccess) {
        boolean actual = loginService.authenticate(username, password);
        Assert.assertEquals(actual, expectedSuccess);
    }
}

2. Parallel Data Providers

By default, data rows execute sequentially. Setting @DataProvider(parallel = true) executes each row concurrently using TestNG's thread pool:

@DataProvider(name = "searchQueries", parallel = true)
public Object[][] provideQueries() {
    return new Object[][] {
        {"Selenium WebDriver"},
        {"TestNG Concurrency"},
        {"Playwright Async"}
    };
}

The default thread pool size for data providers is 10, configurable via data-provider-thread-count in <suite>.

3. Method Reflection Dynamic Routing

By passing java.lang.reflect.Method into a @DataProvider, a single provider can supply custom data payloads based on the caller method's name:

@DataProvider(name = "universalProvider")
public Object[][] routeData(java.lang.reflect.Method method) {
    if (method.getName().equals("testFastCheckout")) {
        return new Object[][] {{"FastUser", 1}};
    } else {
        return new Object[][] {{"StandardUser", 5}};
    }
}

4. Senior SDET Interview Q&A

  1. When should you return Iterator<Object[]> instead of Object[][]?
    When parsing massive external datasets (e.g., 50,000 rows from CSV or Excel). Object[][] forces the entire dataset into Java heap memory at once, risking OutOfMemoryError. Iterator streams rows on demand, keeping heap consumption minimal.
  2. How do you use a @DataProvider located in another class?
    Declare dataProviderClass = ExternalDataClass.class inside the @Test annotation. The external provider method must be public static.
