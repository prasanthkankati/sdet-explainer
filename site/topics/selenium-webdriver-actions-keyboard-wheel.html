7.2 Keyboard & Wheel Actions

Simulating modifier key chords (keyDown, keyUp, Keys.SHIFT/CONTROL) and native viewport/container scrolling (scrollToElement, scrollByAmount).

Beyond mouse pointer gestures, the Selenium Actions class controls virtual keyboard and scroll wheel input devices. Keyboard actions allow holding down modifier keys (keyDown(Keys.SHIFT), keyUp(Keys.SHIFT)) for uppercase typing or multi-select shortcuts, while Selenium 4.2+ Wheel actions provide native scrollToElement() and scrollByAmount() without requiring JavaScript execution.

Before you start

Prerequisite: 7.1 Mouse Actions

Where it fits

Keyboard and Wheel actions are used in Page Objects for keyboard shortcuts (Ctrl+A, Ctrl+C), multi-row Shift/Ctrl selection, and scrolling infinite-scroll feeds or nested scrollable containers.

Key points

  1. actions.keyDown(Keys.SHIFT).sendKeys("selenium").keyUp(Keys.SHIFT).perform() holds Shift while typing, producing "SELENIUM".
  2. Every keyDown(modifier) MUST be paired with a matching keyUp(modifier), or the modifier key remains stuck down for the rest of the session.
  3. Platform-aware Copy/Paste shortcuts compare Platform.getCurrent().is(Platform.MAC) to choose Keys.COMMAND on macOS vs Keys.CONTROL on Windows/Linux.
  4. actions.scrollToElement(WebElement).perform() scrolls the viewport until the target element is in view.
  5. actions.scrollByAmount(int deltaX, int deltaY).perform() scrolls horizontally by deltaX pixels and vertically by deltaY pixels (positive deltaY scrolls down, negative scrolls up).

How it works

  1. Instantiate Actions actions = new Actions(driver).
  2. For modifier shortcuts, focus the target element, call keyDown(Keys.SHIFT), call sendKeys("abc"), call keyUp(Keys.SHIFT), and finish with .perform().
  3. For scrolling, call actions.scrollToElement(footerElement).perform() or actions.scrollByAmount(0, 500).perform().
  4. For scrolling inside an inner scrollable table or div, create WheelInput.ScrollOrigin.fromElement(scrollableDiv) and call actions.scrollFromOrigin(origin, 0, 300).perform().

Executing Shift-key typing and native Wheel scrolling in Selenium 4:

package dev.selenium.actions; // Declares package

import org.openqa.selenium.By; // Imports By locator class
import org.openqa.selenium.Keys; // Imports Keys enum
import org.openqa.selenium.WebDriver; // Imports WebDriver interface
import org.openqa.selenium.WebElement; // Imports WebElement interface
import org.openqa.selenium.chrome.ChromeDriver; // Imports ChromeDriver
import org.openqa.selenium.interactions.Actions; // Imports Actions class
import org.openqa.selenium.interactions.WheelInput; // Imports WheelInput for ScrollOrigin

public class KeyboardWheelActionsExample { // Declares class
    public static void main(String[] args) { // Main method
        WebDriver driver = new ChromeDriver(); // Starts Chrome session
        try { // Guarded block
            driver.get("https://www.selenium.dev/selenium/web/single_text_input.html"); // Loads input test page
            WebElement input = driver.findElement(By.id("textInput")); // Locates text input
            Actions actions = new Actions(driver); // Creates Actions builder

            actions.click(input) // Focuses the input field
                .keyDown(Keys.SHIFT) // Holds down Shift modifier key
                .sendKeys("sdet") // Types 'sdet' (rendered as 'SDET')
                .keyUp(Keys.SHIFT) // Releases Shift modifier key
                .perform(); // Executes keyboard sequence

            driver.get("https://www.selenium.dev/"); // Navigates to long scrollable page
            WebElement footer = driver.findElement(By.tagName("footer")); // Locates footer element
            actions.scrollToElement(footer).perform(); // Scrolls viewport down to footer natively
            actions.scrollByAmount(0, -300).perform(); // Scrolls back up by 300 pixels

            WheelInput.ScrollOrigin origin = WheelInput.ScrollOrigin.fromViewport(10, 10); // Defines scroll origin
            actions.scrollFromOrigin(origin, 0, 200).perform(); // Scrolls 200px down from origin
        } finally { // Teardown block
            driver.quit(); // Closes browser
        } // Ends finally
    } // Ends main
} // Ends class

Common mistakes

  1. Calling actions.keyDown(Keys.CONTROL).sendKeys("a").perform() without calling .keyUp(Keys.CONTROL), leaving the Control key held down so subsequent normal clicks open new tabs!
  2. Passing a non-modifier key (like Keys.ENTER or "a") to keyDown(), which throws InvalidArgumentException; keyDown() and keyUp() only accept modifier keys (SHIFT, CONTROL, ALT, COMMAND/META).
  3. Hardcoding Keys.CONTROL for Copy/Paste shortcuts on macOS where Chrome expects Keys.COMMAND; fix by checking Platform.getCurrent().is(Platform.MAC).

Interview questions

Basics

Which keys are valid arguments for Actions.keyDown() and Actions.keyUp()?
Only modifier keys are valid in keyDown() and keyUp(): Keys.SHIFT, Keys.CONTROL, Keys.ALT, and Keys.COMMAND (or Keys.META). Passing regular character keys or Keys.ENTER throws InvalidArgumentException.

What is the difference between WebElement.sendKeys() and Actions.sendKeys()?
WebElement.sendKeys() focuses the specific target element automatically before typing. Actions.sendKeys(CharSequence) types into whatever element currently has focus in the browser (unless you pass the target WebElement via Actions.sendKeys(element, text)).

How do you scroll down 500 pixels in Selenium 4 without using JavascriptExecutor?
Use the native Wheel Actions API introduced in Selenium 4.2: new Actions(driver).scrollByAmount(0, 500).perform().

How it works

What happens if you call keyDown(Keys.SHIFT) in a test and forget to call keyUp(Keys.SHIFT)?
The virtual keyboard state inside the browser session keeps the Shift key depressed for all subsequent commands in that session, causing later sendKeys() calls to type in uppercase and clicks to behave as Shift+Clicks.

How do you scroll inside a specific scrollable <div> or data grid instead of scrolling the main window?
Create a ScrollOrigin anchored to that container: WheelInput.ScrollOrigin origin = WheelInput.ScrollOrigin.fromElement(scrollableDiv); and call new Actions(driver).scrollFromOrigin(origin, 0, 400).perform().

How do you write a cross-platform Select-All (Ctrl+A / Cmd+A) keyboard shortcut in Selenium Java?
Determine the modifier key dynamically: Keys cmdCtrl = Platform.getCurrent().is(Platform.MAC) ? Keys.COMMAND : Keys.CONTROL; and execute actions.keyDown(cmdCtrl).sendKeys("a").keyUp(cmdCtrl).perform().

Real situations

How do you automate an infinite-scroll product feed on an e-commerce page?
Run a loop that calls new Actions(driver).scrollByAmount(0, 800).perform(), waits briefly for new product cards to render in the DOM, and breaks once driver.findElements(productCardBy).size() reaches the target count.

How do you select multiple non-adjacent items in a custom UI list that supports Ctrl+Click?
Use new Actions(driver).keyDown(Keys.CONTROL).click(item1).click(item3).click(item5).keyUp(Keys.CONTROL).perform().

Why is Actions.scrollToElement(element) preferred over JavascriptExecutor window.scrollTo()?
Actions.scrollToElement() dispatches genuine W3C wheel scroll events through the browser compositor, properly triggering intersection observers and lazy-scroll listeners that sometimes ignore synthetic JS scroll jumps.

Troubleshooting

Why did Actions.keyDown(Keys.ENTER) throw InvalidArgumentException: Key Down action only supports modifier keys?
Keys.ENTER is not a modifier key. To press Enter inside an Actions chain, pass it to sendKeys: actions.sendKeys(Keys.ENTER).perform().

Why did scrollByAmount(0, 500) not move an inner modal dialog's scrollbar?
scrollByAmount(dx, dy) originates at the viewport level (0,0). To scroll an inner modal or overflow container, use scrollFromOrigin(WheelInput.ScrollOrigin.fromElement(modalBody), 0, 500).

How do you clear a stuck modifier key if an exception interrupted an Actions chain between keyDown and keyUp?
Call ((Interactive) driver).resetInputState() in a finally block or recovery helper to release all virtual keys and mouse buttons.

Design choices

When should you use WebElement.sendKeys(Keys.chord(Keys.CONTROL, "a")) versus Actions.keyDown(Keys.CONTROL)?
Use Keys.chord() when sending a quick shortcut directly to a single <input> element. Use Actions.keyDown() when combining keyboard modifiers with mouse clicks (such as Shift+Click or Ctrl+Click across multiple elements).

Why did W3C WebDriver add a dedicated WheelInput device in Selenium 4.2?
Previously, engineers had to fall back to raw JavascriptExecutor scripts for scrolling. Adding WheelInput standardized hardware-accurate touchpad and mouse-wheel scrolling across Chromium, Firefox, and Safari.

What do positive and negative values represent in scrollByAmount(deltaX, deltaY)?
Positive deltaX scrolls right and negative deltaX scrolls left; positive deltaY scrolls down and negative deltaY scrolls up.

Quick answers

  1. Which keys work with keyDown() and keyUp()? Modifier keys only: SHIFT, CONTROL, ALT, COMMAND/META.
  2. How do you scroll down 400px natively in Selenium 4? new Actions(driver).scrollByAmount(0, 400).perform().
  3. How do you scroll until an element is in view? new Actions(driver).scrollToElement(element).perform().
  4. How do you scroll inside a specific overflow <div>? Use actions.scrollFromOrigin(WheelInput.ScrollOrigin.fromElement(div), 0, 300).perform().
  5. How do you release all stuck modifier keys? Call ((Interactive) driver).resetInputState().
