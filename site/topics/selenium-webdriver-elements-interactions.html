4.4 Element Interactions

Interacting with web elements using click(), sendKeys(), clear(), submit(), and automating file uploads.

Selenium WebDriver provides five core interaction commands on the WebElement interface to emulate user actions: click(), sendKeys(), clear(), and submit(). Before executing any interaction, the browser driver automatically runs W3C interactability checks to verify the element is visible, enabled, and not obscured by another element.

Before you start

Prerequisite: 4.3 Element Information & State

Where it fits

Element interaction methods form the action methods inside Page Object classes (such as enterUsername(), clickLogin(), and uploadResume()).

Key points

  1. element.click() scrolls the element into view, verifies its center point is hit-testable (not covered by an overlay), and dispatches a native click.
