2.5 Arrays (1D & 2D Object[][])

1. Definition

An array is a fixed-size block allocated on the Heap whose elements sit side by side by 0-based index, and 2D Object[][] arrays supply multi-row test inputs to TestNG @DataProvider.

2. Memory hook

Fixed size on Heap, 0-based slots, length is a field (no parentheses!).

  • Fixed length: Once new String[5] runs, its size stays 5 forever; growable lists need ArrayList.
  • arr.length vs str.length(): arrays use a property without (); Strings use a method with ().
  • Object[][] holds rows of mixed types (Strings, numbers, booleans) directly for TestNG.

3. 1D Array vs 2D Object[][] in Heap

Heap Layout of Arrays contiguous slots indexed from 0
A 2D array in Java is an array of pointers where each slot points to a separate row array.

5. Code example: 2D Object[][] matching TestNG DataProvider shape

import java.util.Arrays;

public class DataMatrixDemo {
    static Object[][] loginRows() {                  // exact return type required by @DataProvider
        return new Object[][] {
            { "user1", "pass123", true },            // row 0: username, password, expectedSuccess
            { "baduser", "wrong", false }            // row 1: invalid credentials case
        };
    }

    public static void main(String[] args) {
        Object[][] rows = loginRows();
        System.out.println("Row 1 user = " + rows[1][0]); // index 1 -> "baduser"
        System.out.println("Matrix = " + Arrays.deepToString(rows));
    }
}

6. Execution flow, step by step

  1. Calling loginRows() allocates an outer Object[] of length 2 on the Heap.
  2. Slot [0] points to a 3-element row array containing two Strings and a boxed Boolean.TRUE.
  3. Slot [1] points to the second row array; valid outer indexes are 0 and 1.
  4. Accessing rows[2][0] would throw ArrayIndexOutOfBoundsException immediately.
  5. Arrays.toString(rows) prints ugly memory hashes on 2D arrays; Arrays.deepToString(rows) prints nested contents cleanly.

8. Why it matters

Arrays give zero-overhead contiguous storage and instant O(1) slot lookup, yet they never grow once created.

SDET link: TestNG's @DataProvider passes Object[][] straight from Apache POI Excel readers into parameterized tests, executing each row independently in CI.

9. Quick test

What gets printed if you run System.out.println(new int[]{1,2}); directly? The array type/hashcode (like [I@15db9742) — wrap it in Arrays.toString(...) to print elements.
