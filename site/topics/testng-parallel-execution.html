4.1 Parallel Execution: methods, tests & classes

Scaling automated test throughput: configuring parallel modes in testng.xml, thread-count sizing, and eliminating race conditions.

In modern CI/CD pipelines, executing 500 Selenium tests sequentially can easily exceed 2 hours. TestNG's native multi-threading architecture reduces regression duration to minutes by distributing tests across worker thread pools.

1. The Four Parallel Modes

Mode (parallel="...")Execution MechanismThread Safety Requirement
classes (Recommended)Each test class executes in its own thread. Methods inside the class run sequentially.Low to moderate. Static fields must not be shared across classes.
methodsEvery single @Test method runs in a separate thread concurrently.High. WebDriver must use ThreadLocal. No shared class state.
testsEach <test> block in testng.xml runs in parallel.Ideal for parallel cross-browser runs (e.g. Chrome vs Firefox).
instancesTests on different class instances run in separate threads.Used with factory test patterns.

2. Suite Configuration Example

<suite name="ParallelExecutionSuite" parallel="classes" thread-count="4">
  <test name="RegressionPart1">
    <classes>
      <class name="com.sdet.tests.SearchTest" />
      <class name="com.sdet.tests.CheckoutTest" />
      <class name="com.sdet.tests.ProfileTest" />
      <class name="com.sdet.tests.PaymentTest" />
    </classes>
  </test>
</suite>

3. Senior SDET Interview Q&A

  1. What causes race conditions when running Selenium tests with parallel="methods"?
    Using a standard static WebDriver driver field. When Method A and Method B execute concurrently on separate threads, both threads overwrite the same memory reference, causing commands intended for Browser A to be sent to Browser B. Solution: ThreadLocal<WebDriver>.
  2. How do you size thread-count in a Jenkins/Docker agent?
    Rule of thumb: 1 headless browser session consumes roughly 1 vCPU core and 1GB RAM. On a 4-core, 8GB agent, set thread-count="3" or "4" to prevent CPU thrashing and memory exhaustion.
