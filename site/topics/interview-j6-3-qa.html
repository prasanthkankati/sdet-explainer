J6.3 Question Bank: File I/O: Properties, JSON (Jackson) &amp; Excel (Apache POI) (19 Questions)

Tier 1: Core Definitions, Classification & Theory (Q1–Q3)

  1. Why use Properties instead of a static Java constants class for URLs and browsers?
    Changing a static constant requires editing source code and recompiling the project, whereas .properties files and CLI -D overrides let Jenkins or testers switch from local Chrome to staging headless runs without recompiling.
  2. What is the difference between HSSFWorkbook and XSSFWorkbook in Apache POI?
    HSSFWorkbook reads legacy binary .xls spreadsheets (Office 97–2003), while XSSFWorkbook reads modern ZIP-XML .xlsx files. Calling WorkbookFactory.create(stream) handles both automatically.
  3. Why prefer Path.of(...) over concatenating strings with / or \\?
    Path.of("src", "test", "resources", "qkart.json") lets Java insert the host OS file separator automatically on both Windows developer laptops and Linux CI containers.

Tier 2: How It Works & Internal Mechanics (Q4–Q6)

  1. How does Jackson know the element type inside List<User> when type erasure removes User at runtime?
    Passing an anonymous subclass new TypeReference<List<User>>() {} retains the parameterized superclass metadata in bytecode, which Jackson reads via reflection.
  2. How does DataFormatter.formatCellValue(cell) prevent type mismatch crashes in Excel readers?
    Instead of forcing a single cell type getter like getStringCellValue() or getNumericCellValue(), DataFormatter inspects the cell type and formatting mask and converts numbers, dates, booleans, or formulas cleanly to a Java String.
  3. What happens when you load a file from src/test/resources via getClass().getClassLoader().getResourceAsStream("config.properties")?
    Maven/Gradle copies src/test/resources onto the runtime classpath, so loading via the classloader works even when the project runs from a packaged test JAR where direct filesystem paths differ.

Tier 3: Real-World SDET & Selenium Scenarios (Q7–Q9)

  1. How do you pass nested order payloads (address object + array of product SKUs) into a Selenium end-to-end test?
    Store them in JSON instead of Excel. Modeling nested arrays and objects cleanly in flat Excel columns turns messy quickly, whereas Jackson deserializes nested JSON into typed Java records or POJOs cleanly.
  2. Your Maven command passes mvn test -Durl=https://www.selenium.dev/, yet tests still hit QKart from config.properties. Why?
    Your config loader checked props.getProperty("url") without checking System.getProperty("url") first; system properties passed with -D must always take precedence over file defaults.
  3. How does a reader avoid failing on trailing blank rows formatted in Excel?
    Either check for empty row values (`row == null` or every cell blank) before adding to the result list, or iterate using sheet.getLastRowNum() while skipping rows where the first key cell is empty.

Tier 4: Troubleshooting, Exceptions & Failure Modes (Q10–Q12)

  1. Apache POI throws IllegalStateException: Cannot get a STRING value from a NUMERIC cell when reading test zip codes. What is the fix?
    Replace cell.getStringCellValue() with formatter.formatCellValue(cell) or call DataFormatter across every column uniformly.
  2. Jackson throws UnrecognizedPropertyException after adding a new notes column to a JSON test fixture. How can the POJO stay resilient?
    Either add the matching field to your POJO, annotate the class with @JsonIgnoreProperties(ignoreUnknown = true), or configure DeserializationFeature.FAIL_ON_UNKNOWN_PROPERTIES to false on the ObjectMapper.
  3. Why does getResourceAsStream("config.properties") return null?
    Either the file sits outside src/test/resources (so Maven did not copy it to target/test-classes) or a leading slash mismatch happened between Class.getResourceAsStream (relative to package without leading slash) and ClassLoader.getResourceAsStream (always from classpath root without leading slash).

Tier 5: Design Choices & Rapid-Fire Recall (Q13–Q19)

  1. When should a QA team pick JSON over Excel for Selenium test data?
    Pick JSON when engineers own the data, tests need nested objects/arrays, and clean Git line-by-line code reviews matter. Pick Excel when non-technical analysts author flat tables in spreadsheets.
  2. Should ObjectMapper be created per test or stored as a static singleton?
    Store a single configured ObjectMapper constant. Once configured at startup, it is thread-safe and caches bean serializers/deserializers for fast execution across parallel threads.
  3. Why avoid storing sensitive production passwords directly inside committed .properties or JSON files?
    Credentials committed to Git leak into history permanently. Inject secrets via CI environment variables (System.getenv()) or Maven -D arguments overriding placeholder properties.
  4. How should CLI flags override config files?
    Check System.getProperty(key) first and fall back to the loaded Properties object.
  5. What fixes POI numeric-vs-string crashes on Excel cells?
    Use DataFormatter.formatCellValue(cell) alongside CREATE_NULL_AS_BLANK.
  6. How does Jackson deserialize a List<User>?
    Pass new TypeReference<List<User>>() {} to ObjectMapper.readValue().
  7. Should ObjectMapper be shared across threads?
    Yes; once configured, a single static instance is thread-safe and faster.
