3.3 Essential String Methods & Regex for SDETs

1. Definition

Java String methods clean browser whitespace, slice UI labels, split tables, and pair with Regular Expressions in replaceAll() and matches() to extract numbers, IDs, and prices.

2. Memory hook

strip() cleans Unicode UI spaces; replace() is literal; replaceAll() runs Regex!

  • strip() vs trim(): trim() misses non-breaking web spaces (&nbsp; / \u00A0); strip() (Java 11+) clears all Unicode whitespace.
  • replace() vs replaceAll(): replace(".", "-") matches a literal dot; replaceAll(".", "-") treats . as Regex ANY char and erases every letter!
  • Regex essentials: \d+ digits, \s+ spaces, [^0-9.] anything except numbers/dot.

5. Code example: extracting order ID and price from UI text

import java.util.regex.Matcher;
import java.util.regex.Pattern;

public class StringRegexSdet {
    public static void main(String[] args) {
        String banner = "  Order #QK-9042 confirmed | Total: $49.99  ".strip(); // Unicode trim
        String cleanAmount = banner.split("\\|")[1].replaceAll("[^0-9.]", "");      // "49.99"
        double paid = Double.parseDouble(cleanAmount);

        Matcher m = Pattern.compile("QK-(\\d+)").matcher(banner); // capture digits after QK-
        String orderNum = m.find() ? m.group(1) : "";             // "9042"
        System.out.println("Order=" + orderNum + " Paid=" + paid);
    }
}

6. Execution flow, step by step

  1. .strip() cleans surrounding spaces from the raw Selenium getText() string.
  2. split("\\|") splits on literal | (escaped because | means OR in Regex) into two parts.
  3. replaceAll("[^0-9.]", "") strips currency symbols, words, and spaces, leaving "49.99".
  4. Pattern.compile("QK-(\\d+)") builds a compiled Regex matcher with a capture group (\\d+).
  5. m.find() locates the match and m.group(1) extracts the numeric ID "9042".

8. Why it matters

Real web pages rarely render raw clean integers — fluent cleanup + Regex turns messy DOM strings into reliable assertions.

SDET link: When validating product totals on QKart or version badges on https://www.selenium.dev/, strip currency prefixes/non-breaking spaces cleanly before parsing doubles or matching dynamic order numbers.

9. Quick test

What does "a.b.c".replaceAll(".", "X") return? "XXXXX" — unescaped dot matches EVERY character in Regex; use replace(".", "X") for literal dot.
