5.1 Collections Hierarchy & Generics (Type Safety)

1. Definition

The Collections Framework splits into Iterable -> Collection (List, Set, Queue) for single items and Map for key-value pairs, while Generics <T> enforce element types at compile time before Type Erasure.

2. Memory hook

Single items extend Collection (List/Set/Queue); key->value uses Map separately; Collection is an interface, Collections is a helper class!

  • Why Map is NOT under Collection: Collection operates on single elements (add(e)), while Map pairs put(k, v).
  • Collection vs Collections: Collection is the parent interface; Collections holds static helpers like Collections.sort() and unmodifiableList().
  • Generics + Type Erasure: List<WebElement> stops wrong types at compile time; at runtime bytecode erases <T> cleanly for backward compatibility.

5. Code example: generics compile safety + generic Selenium helper

import java.util.*;

public class CollectionsOverviewDemo {
    static <T> T firstOrNull(List<T> items) {       // reusable generic method
        return (items == null || items.isEmpty()) ? null : items.get(0);
    }

    public static void main(String[] args) {
        List<String> tabs = new ArrayList<>();    // diamond <> infers String on right side
        tabs.add("https://www.selenium.dev/");
        tabs.add("https://qkart-qa-web.labs.crio.do/");
        // tabs.add(123);                         // compile error thanks to Generics!

        Collections.sort(tabs);                   // Collections utility class helper
        System.out.println("First URL: " + firstOrNull(tabs));
    }
}

6. Execution flow, step by step

  1. List<String> tabs = new ArrayList<>(); declares an interface variable pointing to a concrete ArrayList.
  2. Adding an integer tabs.add(123) fails right during compilation rather than crashing a nightly Jenkins build.
  3. Collections.sort(tabs) sorts the list in-place using natural alphabetical order.
  4. Calling generic helper firstOrNull(tabs) infers T = String and returns a typed String with zero manual casts.
  5. After compilation, Type Erasure turns <T> into plain Object inside bytecode plus compiler-inserted safe casts.

8. Why it matters

Program-to-interface declarations (List<T>, Map<K,V>) + Generics catch wrong types early and swap implementations effortlessly.

SDET link: driver.findElements(...) returns List<WebElement>, driver.getWindowHandles() returns Set<String>, and test-data rows use Map<String, String> — covering every branch of Java Collections.

9. Quick test

Does HashMap implement the Collection interface? No — Map is a separate root interface because entries take keys and values rather than single elements.
