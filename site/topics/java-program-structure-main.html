2.1 Program Structure & main() Method Decoded

Exact top-to-bottom layout of a Java source file, every modifier in public static void main(String[] args), and how System.out.println writes to stdout.

A Java source file enforces a strict top-level declaration order so the compiler maps package namespaces, external imports, and class definitions unambiguously. When executing a standalone program, the JVM locates and invokes the exact public static void main(String[] args) entry point signature before running application logic.

Before you start

Prerequisite: 1.4 Metaspace, static Memory & Execution Engine (JIT + GC)

Where it fits

Every Page Object class, utility helper, and standalone Selenium runner script follows the package, import, and class file structure, while TestNG invokes @Test methods via reflection instead of requiring a main() method.

Key points

  1. Top-level declarations inside a .java file must appear in exact order: optional package statement first, optional import statements second, and class/interface declarations third.
  2. If a source file contains a public class Foo, the filename on disk must match Foo.java identically with matching case.
  3. The JVM entry signature public static void main(String[] args) requires public (accessible to the external JVM launcher), static (callable without instantiating the class), void (returns no value to the JVM), and a String[] parameter for CLI arguments.
  4. You can overload main() with different parameter lists inside the same class, and rename parameter args or use varargs String... args, because the JVM only looks up the String[] descriptor.
  5. In System.out.println(), System is a final class in java.lang (auto-imported), out is a public static final PrintStream field, and println() is an overloaded instance method on PrintStream.
  6. Omitting public or static or altering the return type compiles cleanly with javac, but fails at launch because the JVM launcher rejects non-matching entry signatures.

How it works

  1. Line 1 declares package dev.java.core; matching the folder structure dev/java/core under the source root.
  2. import statements resolve external types from java.* and Selenium JARs, while classes inside java.lang (String, System, Object) are imported implicitly.
  3. When java EntryPointDemo staging runs, the JVM loads EntryPointDemo, creates a 1-element String[] containing "staging", and pushes the main Stack Frame.
  4. Inside main, System.out accesses the static PrintStream bound to OS standard output and calls println() to flush characters followed by a newline.

Canonical Java source structure decoding main(), CLI arguments, and System.out.println:

package dev.java.core; // Must be the first non-comment statement in the file

import org.openqa.selenium.WebDriver; // Imports WebDriver interface from Selenium library
import org.openqa.selenium.chrome.ChromeDriver; // Imports ChromeDriver class

public class EntryPointDemo { // Public class name must equal EntryPointDemo.java
    public static void main(String[] args) { // Exact JVM entry signature
        String env = args.length > 0 ? args[0] : "qa"; // Reads optional CLI argument or defaults to qa
        System.out.println("Running suite on env: " + env); // Invokes PrintStream.println on System.out
        WebDriver driver = new ChromeDriver(); // Initializes Chrome browser session
        driver.get("https://qkart-qa-web.labs.crio.do/login"); // Navigates to QKart login page
        driver.quit(); // Terminates browser and driver process
    } // Ends main method
} // Ends EntryPointDemo class

Common mistakes

  1. Placing an import statement above the package statement; javac rejects the file with a compile-time syntax error.
  2. Manually typing import java.lang.String; or putting multiple public top-level classes in a single .java file; java.lang is imported automatically and each .java file permits at most one public top-level class.
  3. Changing void to int on main() to return an exit status code; use System.exit(1) instead because the JVM requires void on main.
  4. Adding a main() method inside TestNG Page Object or @Test classes; TestNG uses reflection to invoke @Test methods directly and skips main().

Interview questions

Basics

Why must main() be declared public and static?
public exposes the method to the external JVM launcher outside the class's package. static allows the JVM to invoke main() directly on the class without first creating an object via a constructor, avoiding ambiguity if a class only has parameterized constructors. Removing either keyword compiles with javac, but fails when launching with java.

Why is the return type of main() strictly void?
Unlike C or C++ where main() returns an integer exit code to the operating system shell, the JVM manages thread termination and daemon cleanup after main() finishes. Because no caller inside Java receives a return value from main(), the specification enforces void. To pass a non-zero exit code to a CI shell, call System.exit(code) explicitly.

Can a single .java source file contain more than one class?
Yes, a single .java file can contain multiple top-level classes, provided at most one of them is declared public. When one class is public, the file name must match that public class name identically. Each class inside the file compiles into its own separate .class bytecode file.

How it works

Break down every word in System.out.println("Pass").
System is a final utility class inside java.lang that cannot be instantiated because its constructor is private. out is a public static final PrintStream reference field initialized when the JVM boots standard I/O streams. println("Pass") is an instance method on that PrintStream object that writes the text followed by a line separator.

Can you overload main() in a Java class, and which version runs at startup?
Yes, you can declare additional methods named main with different parameter lists, including public static void main(int x) or main(String a, String b). When the JVM launches the class, it always searches strictly for public static void main(String[] args) (or String... args) as the entry point. Overloaded variants only run if called explicitly from code.

How do package and import declarations affect compiled bytecode?
Neither package nor import copies external code into the compiled .class file. import is purely a compile-time convenience so javac expands WebDriver into its fully qualified binary name org/openqa/selenium/WebDriver inside the bytecode constant pool. The package statement embeds that prefix directly into the class's binary identity.

Real situations

Why do TestNG and JUnit test classes run in Maven without a main() method?
Maven invokes TestNG's or JUnit's own runner entry point, which already owns a main() method inside the test framework JAR. The runner uses Java reflection to scan your compiled test classes, instantiate them, and execute methods annotated with @BeforeMethod, @Test, and @AfterMethod. Adding main() inside every test class is unnecessary boilerplate.

How do command-line arguments passed via java Runner staging headless arrive inside args?
The JVM splits whitespace-separated tokens following the class name and passes them as a zero-indexed String[] array into main. In that launch command, args[0] equals "staging", args[1] equals "headless", and args.length equals 2. If no arguments are passed, args is a valid empty array of length 0, never null.

When a Selenium utility uses java.sql.Date and java.util.Date in the same class, how do imports work?
If both classes share the simple name Date, importing both with single-type imports causes a compile-time ambiguity error. Import the more common one normally (for example, import java.util.Date;) and reference the second one by its fully qualified name java.sql.Date inline.

Troubleshooting

Why does running java LoginTest fail with 'Main method not found in class LoginTest, please define the main method as: public static void main(String[] args)'?
This message appears when the class lacks the exact public static void main(String[] args) signature—either static was forgotten, public was omitted, the return type is non-void, or the class is a TestNG test meant to run through TestNG/Maven instead of standalone java. Verify the exact signature or execute the class via mvn test.

What happens if public static void main(String[] args) accesses args[0] when no arguments were passed?
Because args is allocated as a zero-length array new String[0], indexing args[0] immediately throws java.lang.ArrayIndexOutOfBoundsException: Index 0 out of bounds for length 0. Always guard index access with if (args.length > 0) or prefer Maven -D system properties via System.getProperty().

Why does javac report 'class Foo is public, should be declared in a file named Foo.java'?
Java enforces that any top-level public class resides in a source file whose exact name (including capitalization) matches the class name. Renaming either the class or the .java file fixes the compilation failure immediately.

Design choices

Why does Java auto-import java.lang and the current package while requiring explicit imports for everything else?
Classes inside java.lang (String, Object, System, wrapper classes, and core exceptions) appear in practically every Java file, so explicit imports for them would bloat every file. Requiring explicit imports for external packages like org.openqa.selenium makes external dependencies clear to maintainers and prevents accidental name collisions.

Why does Java discourage wildcard imports like import org.openqa.selenium.*; in production test frameworks?
Wildcard imports hide which exact classes a file depends on and can break compilation abruptly if a newer library version introduces a class with a conflicting simple name. Explicit single-class imports keep dependencies transparent and compile cleanly across upgrades.

In a Java automation framework, why is passing configuration via -Denv=staging (System.getProperty) preferred over main(String[] args)?
Maven Surefire and TestNG control the JVM entry point themselves, so test classes do not receive custom CLI strings through args. JVM system properties set via -Dkey=value are readable anywhere inside @BeforeSuite, DriverFactory, or config readers via System.getProperty("env").

Quick answers

  1. What is the exact declaration order at the top of a .java file? package first, import second, class declaration third.
  2. Which package is imported automatically into every Java class? java.lang.
  3. What is System.out? A public static final PrintStream field on java.lang.System.
  4. What is the value of args in main() if no CLI arguments are provided? An empty String[0] array (never null).
  5. Can main() be overloaded? Yes, though the JVM only executes public static void main(String[] args) at startup.
  6. Do TestNG @Test classes need a main() method? No, TestNG invokes annotated methods via reflection.
