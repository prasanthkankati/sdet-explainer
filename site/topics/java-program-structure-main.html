2.1 Program Structure & main() Method Decoded

1. Definition

A Java file follows one fixed top-to-bottom order — package, imports, class, and methods — and execution starts only at the exact method signature public static void main(String[] args).

2. Memory hook

P-I-C-M on top (Package, Import, Class, Main) — and P-S-V-M on the starter line.

  • Order matters: package first, then import lines, then the class block.
  • public static void main(String[] args) lets the JVM call your entry point directly without first doing new ClassName().
  • java.lang is auto-imported: String and System work without an explicit import.

5. Code example: running a file with package, import & CLI args

package qkart;                          // MUST be line 1 (matches qkart folder)

import java.time.LocalDate;             // explicit import (java.lang needs none)

public class SmokeBoot {                // file MUST be named SmokeBoot.java
    public static void main(String[] args) {
        String env = args.length > 0 ? args[0] : "qa"; // read CLI flag safely
        System.out.println("Running QKart on " + env + " (" + LocalDate.now() + ")");
    }
}
javac -d out SmokeBoot.java
java -cp out qkart.SmokeBoot staging

6. Execution flow, step by step

  1. javac checks that SmokeBoot.java sits in matching casing and starts with package, then import, then public class SmokeBoot.
  2. Running java qkart.SmokeBoot staging loads SmokeBoot.class from classpath.
  3. The JVM searches specifically for public static void main(String[] args); if static is missing, startup aborts.
  4. Java wraps the word staging into a 1-element array args = ["staging"] and invokes main.
  5. System.out accesses the static console stream object on java.lang.System and prints the line.

8. Why it matters

Overloaded main(int x) compiles fine as a helper, yet the JVM ignores it and only triggers public static void main(String[] args).

SDET link: TestNG tests skip writing main() in your test files because TestNG itself supplies the main() engine and runs your @Test methods via reflection — yet standalone Selenium scripts still start inside main().

9. Quick test

What happens if you declare public void main(String[] args) without static? It compiles cleanly, but running java throws an error because no main method was found as static.
