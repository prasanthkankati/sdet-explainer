6.3 File I/O: Properties, JSON (Jackson) &amp; Excel (Apache POI)

Externalizing URLs, credentials, and multi-row datasets keeps test code decoupled from hardcoded values across environments.

Hardcoding https://qkart-qa-web.labs.crio.do/ or login passwords inside Java test methods forces code edits and recompiles whenever staging URLs or test accounts change. Every production SDET framework reads key-value configuration from .properties files, hierarchical payloads from JSON with Jackson, and tabular matrices from Excel workbooks using Apache POI.

Before you start

Prerequisite: 6.2 try-catch-finally, try-with-resources, throw/throws &amp; Custom Exceptions

Where it fits

Data-driven testing sits right behind TestNG @DataProvider and environment configuration. A clean framework loads environment flags at suite startup from config.properties, deserializes nested API/UI test data from JSON via Jackson ObjectMapper, and reads spreadsheet sheets cleanly through Apache POI inside try-with-resources.

Key points

  1. Modern java.nio.file foundation: Prefer Path.of(...) and Files over legacy java.io.File for cross-platform path joining and cleaner I/O exceptions.
  2. Properties for flat config: Load key=value settings from src/test/resources via ClassLoader.getResourceAsStream() or Files.newInputStream(), and check System.getProperty() first so CI command-line flags (-Denv=staging) override file defaults.
  3. Jackson ObjectMapper for JSON: Reuse a single thread-safe ObjectMapper instance to bind JSON objects to Java POJOs or collections using TypeReference<List<LoginData>>.
  4. Apache POI for Excel (.xlsx vs .xls): Use XSSFWorkbook (or WorkbookFactory.create(stream)) for modern OOXML .xlsx files instead of legacy HSSFWorkbook, and iterate rows with DataFormatter to convert numbers and dates safely to strings without type crashes.
  5. Always stream-close and handle blank cells: Open streams and workbooks inside try-with-resources and pass Row.MissingCellPolicy.CREATE_NULL_AS_BLANK to avoid NullPointerException on empty Excel cells.

How it works

  1. For configuration properties, resolve environment variable or System.getProperty(key) first; if absent, fall back to the loaded Properties object.
  2. For Jackson JSON deserialization, define a matching POJO with no-arg constructor and fields (or getters/setters), then call mapper.readValue(input, new TypeReference<List<UserCase>>() {}).
  3. For Apache POI Excel reading, open both the InputStream and the Workbook in try-with-resources, locate row 0 as headers or start at row 1 for test cases, and wrap each cell in new DataFormatter().formatCellValue(cell).
  4. Convert the parsed records into an Object[][] matrix or an iterator so TestNG's @DataProvider feeds one scenario per test invocation.

Reading config.properties, Jackson JSON list, and Apache POI Excel rows safely

package com.qkart.io; // Data and configuration readers package

import com.fasterxml.jackson.core.type.TypeReference; // Captures generic List<T> type at runtime
import com.fasterxml.jackson.databind.ObjectMapper; // Thread-safe Jackson JSON parser
import java.io.IOException; // Checked I/O failure from readers
import java.io.InputStream; // Stream closed via try-with-resources
import java.nio.file.Files; // NIO helper for safe file streams
import java.nio.file.Path; // OS-independent file path
import java.util.Properties; // Key-value properties loader
import org.apache.poi.ss.usermodel.Cell; // Excel cell abstraction (works for xls/xlsx)
import org.apache.poi.ss.usermodel.DataFormatter; // Formats numeric/date/boolean cells cleanly to String
import org.apache.poi.ss.usermodel.Row; // Excel row interface
import org.apache.poi.ss.usermodel.Sheet; // Excel worksheet interface
import org.apache.poi.ss.usermodel.Workbook; // Workbook implementing Closeable
import org.apache.poi.ss.usermodel.WorkbookFactory; // Auto-detects HSSF vs XSSF workbook format

public class TestDataReaders { // Unified file I/O utility class

    private static final ObjectMapper MAPPER = new ObjectMapper(); // Reuse one heavy ObjectMapper instance

    public static String getConfig(Path propsPath, String key) { // Reads system override then properties file
        String cliOverride = System.getProperty(key); // Checks -Dkey=value passed from Maven/CI
        if (cliOverride != null && !cliOverride.isBlank()) { // Prefer command-line override when provided
            return cliOverride; // Returns CI value immediately
        } // End CLI check
        Properties props = new Properties(); // Empty properties table
        try (InputStream in = Files.newInputStream(propsPath)) { // Auto-closes file stream
            props.load(in); // Parses key=value lines into memory
            return props.getProperty(key); // Returns configured URL e.g. https://qkart-qa-web.labs.crio.do/
        } catch (IOException ex) { // Wrap checked error into descriptive runtime failure
            throw new IllegalStateException("Cannot read properties: " + propsPath, ex); // Fail fast with cause
        } // End try-with-resources
    } // End getConfig

    public static <T> T readJson(Path jsonPath, TypeReference<T> typeRef) { // Generic typed JSON reader
        try (InputStream in = Files.newInputStream(jsonPath)) { // Opens JSON stream safely
            return MAPPER.readValue(in, typeRef); // Maps JSON array or object cleanly to Java types
        } catch (IOException ex) { // Handle missing file or malformed JSON syntax
            throw new IllegalStateException("Cannot parse JSON file: " + jsonPath, ex); // Keep root cause
        } // End JSON try-with-resources
    } // End readJson

    public static Object[][] readExcelMatrix(Path xlsxPath, String sheetName) { // Reads non-header rows for @DataProvider
        DataFormatter formatter = new DataFormatter(); // Converts numbers like ZIP codes cleanly to String
        try (InputStream in = Files.newInputStream(xlsxPath); // Opens workbook input stream
             Workbook wb = WorkbookFactory.create(in)) { // Closes workbook and releases ZIP file handles
            Sheet sheet = wb.getSheet(sheetName); // Selects named tab in Excel workbook
            int rowCount = sheet.getPhysicalNumberOfRows(); // Counts populated rows starting from header
            int colCount = sheet.getRow(0).getLastCellNum(); // Width determined from header row
            Object[][] matrix = new Object[rowCount - 1][colCount]; // Allocate rows minus header row
            for (int r = 1; r < rowCount; r++) { // Skip header row 0 and read test data rows
                Row row = sheet.getRow(r); // Fetch row safely
                for (int c = 0; c < colCount; c++) { // Walk each expected column index
                    Cell cell = row.getCell(c, Row.MissingCellPolicy.CREATE_NULL_AS_BLANK); // Avoid NPE on blank cell
                    matrix[r - 1][c] = formatter.formatCellValue(cell); // Preserve exact text formatting
                } // End column loop
            } // End row loop
            return matrix; // Return Object[][] directly usable by TestNG @DataProvider
        } catch (IOException ex) { // Catch corrupt workbook or missing path
            throw new IllegalStateException("Failed reading Excel file: " + xlsxPath, ex); // Rethrow unchecked
        } // End Excel try-with-resources
    } // End readExcelMatrix
} // End TestDataReaders

Common mistakes

  1. Calling cell.getStringCellValue() on numeric Excel cells: Reading an integer password or PIN via getStringCellValue() throws IllegalStateException; always use DataFormatter.formatCellValue(cell).
  2. Hardcoding Windows backslashes like src\test\resources\data.json: This breaks immediately on Linux Jenkins runners; always use Path.of("src", "test", "resources", "data.json") or classpath resources.
  3. Creating a brand-new new ObjectMapper() inside every test row: Instantiating ObjectMapper repeatedly wastes CPU scanning annotations and allocating reflection caches.
  4. Leaving Workbook or FileInputStream unclosed: Open handles lock Excel files on Windows agents and trigger file-descriptor exhaustion on long suites.

Interview questions

Basics

Why use Properties instead of a static Java constants class for URLs and browsers?
Changing a static constant requires editing source code and recompiling the project, whereas .properties files and CLI -D overrides let Jenkins or testers switch from local Chrome to staging headless runs without recompiling.

What is the difference between HSSFWorkbook and XSSFWorkbook in Apache POI?
HSSFWorkbook reads legacy binary .xls spreadsheets (Office 97–2003), while XSSFWorkbook reads modern ZIP-XML .xlsx files. Calling WorkbookFactory.create(stream) handles both automatically.

Why prefer Path.of(...) over concatenating strings with / or \\?
Path.of("src", "test", "resources", "qkart.json") lets Java insert the host OS file separator automatically on both Windows developer laptops and Linux CI containers.

How it works

How does Jackson know the element type inside List<User> when type erasure removes User at runtime?
Passing an anonymous subclass new TypeReference<List<User>>() {} retains the parameterized superclass metadata in bytecode, which Jackson reads via reflection.

How does DataFormatter.formatCellValue(cell) prevent type mismatch crashes in Excel readers?
Instead of forcing a single cell type getter like getStringCellValue() or getNumericCellValue(), DataFormatter inspects the cell type and formatting mask and converts numbers, dates, booleans, or formulas cleanly to a Java String.

What happens when you load a file from src/test/resources via getClass().getClassLoader().getResourceAsStream("config.properties")?
Maven/Gradle copies src/test/resources onto the runtime classpath, so loading via the classloader works even when the project runs from a packaged test JAR where direct filesystem paths differ.

Real situations

How do you pass nested order payloads (address object + array of product SKUs) into a Selenium end-to-end test?
Store them in JSON instead of Excel. Modeling nested arrays and objects cleanly in flat Excel columns turns messy quickly, whereas Jackson deserializes nested JSON into typed Java records or POJOs cleanly.

Your Maven command passes mvn test -Durl=https://www.selenium.dev/, yet tests still hit QKart from config.properties. Why?
Your config loader checked props.getProperty("url") without checking System.getProperty("url") first; system properties passed with -D must always take precedence over file defaults.

How does a reader avoid failing on trailing blank rows formatted in Excel?
Either check for empty row values (`row == null` or every cell blank) before adding to the result list, or iterate using sheet.getLastRowNum() while skipping rows where the first key cell is empty.

Troubleshooting

Apache POI throws IllegalStateException: Cannot get a STRING value from a NUMERIC cell when reading test zip codes. What is the fix?
Replace cell.getStringCellValue() with formatter.formatCellValue(cell) or call DataFormatter across every column uniformly.

Jackson throws UnrecognizedPropertyException after adding a new notes column to a JSON test fixture. How can the POJO stay resilient?
Either add the matching field to your POJO, annotate the class with @JsonIgnoreProperties(ignoreUnknown = true), or configure DeserializationFeature.FAIL_ON_UNKNOWN_PROPERTIES to false on the ObjectMapper.

Why does getResourceAsStream("config.properties") return null?
Either the file sits outside src/test/resources (so Maven did not copy it to target/test-classes) or a leading slash mismatch happened between Class.getResourceAsStream (relative to package without leading slash) and ClassLoader.getResourceAsStream (always from classpath root without leading slash).

Design choices

When should a QA team pick JSON over Excel for Selenium test data?
Pick JSON when engineers own the data, tests need nested objects/arrays, and clean Git line-by-line code reviews matter. Pick Excel when non-technical analysts author flat tables in spreadsheets.

Should ObjectMapper be created per test or stored as a static singleton?
Store a single configured ObjectMapper constant. Once configured at startup, it is thread-safe and caches bean serializers/deserializers for fast execution across parallel threads.

Why avoid storing sensitive production passwords directly inside committed .properties or JSON files?
Credentials committed to Git leak into history permanently. Inject secrets via CI environment variables (System.getenv()) or Maven -D arguments overriding placeholder properties.

Quick answers

  1. How should CLI flags override config files? Check System.getProperty(key) first and fall back to the loaded Properties object.
  2. What fixes POI numeric-vs-string crashes on Excel cells? Use DataFormatter.formatCellValue(cell) alongside CREATE_NULL_AS_BLANK.
  3. How does Jackson deserialize a List<User>? Pass new TypeReference<List<User>>() {} to ObjectMapper.readValue().
  4. Should ObjectMapper be shared across threads? Yes; once configured, a single static instance is thread-safe and faster.
