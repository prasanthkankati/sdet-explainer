6.3 File I/O: Properties, JSON & Apache POI (Excel)

1. Definition

Externalizing test data keeps URLs, credentials, and multi-row datasets out of Java source code by reading .properties for flat settings, Jackson ObjectMapper for nested JSON, and Apache POI Workbooks for Excel sheets.

2. Memory hook

.properties = flat settings (CLI -D overrides first!); JSON = nested POJOs; Excel/POI = 2D QA sheets (DataFormatter avoids crashes!).

  • Override hierarchy: always check System.getProperty(key) before reading config.properties so Maven flags (-Dbrowser=chrome) win in CI.
  • JSON with Jackson: reuse one static ObjectMapper instance and pass TypeReference<List<User>> for generic collections.
  • Apache POI gotcha: numeric ZIP codes crash getStringCellValue() — use DataFormatter.formatCellValue(cell) + CREATE_NULL_AS_BLANK!

5. Code example: reading properties with CLI override + POI DataFormatter helper

import java.io.*;
import java.nio.file.*;
import java.util.Properties;
import org.apache.poi.ss.usermodel.*;

public class DataReaders {
    static String readProp(Path path, String key) throws IOException {
        String cli = System.getProperty(key);         // -Dkey=val from CI overrides file
        if (cli != null && !cli.isBlank()) return cli;
        Properties props = new Properties();
        try (InputStream in = Files.newInputStream(path)) {
            props.load(in);
            return props.getProperty(key);
        }
    }

    static String safeCell(Row row, int col) {
        Cell cell = row.getCell(col, Row.MissingCellPolicy.CREATE_NULL_AS_BLANK);
        return new DataFormatter().formatCellValue(cell); // reads text/numbers safely as String
    }
}

6. Execution flow, step by step

  1. readProp checks System.getProperty(key) first so mvn test -Durl=https://www.selenium.dev/ overrides local defaults instantly.
  2. Otherwise, Files.newInputStream(path) opens the file stream inside try (...) so handles close automatically.
  3. In Excel readers, WorkbookFactory.create(in) handles both .xlsx and legacy .xls without manual class branching.
  4. MissingCellPolicy.CREATE_NULL_AS_BLANK prevents NullPointerException on skipped spreadsheet cells.
  5. DataFormatter.formatCellValue(cell) safely formats integer pins or dates as Strings without throwing IllegalStateException.

8. Why it matters

Clean external data separation lets one automation binary test dev, QA, and staging environments reliably without recompiling code.

SDET link: TestNG @DataProvider methods call POI/Jackson loaders at suite startup, keeping base URLs (https://www.selenium.dev/, https://qkart-qa-web.labs.crio.do/) configurable in src/test/resources.

9. Quick test

Why does cell.getStringCellValue() crash on a ZIP code like 560001 in Excel? Excel stores 560001 as numeric type; always call new DataFormatter().formatCellValue(cell) instead.
