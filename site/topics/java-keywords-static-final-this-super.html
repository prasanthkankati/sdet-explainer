4.4 Core Keywords: static, final, this, super & instanceof

1. Definition

static binds members to the class rather than instances, final prevents reassignment/overriding/inheritance, this and super distinguish current vs parent members, and instanceof checks runtime object type before downcasting.

2. Memory hook

static = 1 shared per class; final = Locked (const / no-override / no-extend); this = me; super = parent.

  • Why static WebDriver fails in parallel: all threads overwrite the same single class slot on the Heap.
  • 3 uses of final: final variable (cannot reassign ref), final method (cannot override), final class (cannot extend, like String).
  • final vs finally vs finalize: lock keyword vs exception cleanup block vs deprecated GC hook.

5. Code example: this/super disambiguation, final constants & pattern instanceof

class ParentPage {
    protected String title = "Base";
}

public class ChildPage extends ParentPage {
    private final String title = "QKart Login";           // constant per page object
    static int createdCount = 0;                          // shared across all ChildPage instances

    ChildPage() { createdCount++; }

    void inspect(Object driverObj) {
        System.out.println("this=" + this.title + " super=" + super.title); // distinguishes shadowed field
        if (driverObj instanceof String url) {            // Java 16 pattern matching instanceof
            System.out.println("URL length=" + url.length());
        }
    }
    public static void main(String[] args) { new ChildPage().inspect("https://www.selenium.dev/"); }
}

6. Execution flow, step by step

  1. createdCount belongs to ChildPage class once, incrementing on every constructor call.
  2. this.title resolves to ChildPage's field ("QKart Login"), whereas super.title reaches parent field "Base".
  3. final String title blocks any later title = "Other" assignment inside the class.
  4. driverObj instanceof String url verifies runtime type cleanly before binding typed variable url — zero risk of ClassCastException.
  5. Trying to use this or super inside main() refuses to compile because static methods lack an instance.

8. Why it matters

Mixing up static and instance lifetime causes race conditions across parallel tests, while skipping final allows subtle accidental reassignments.

SDET link: Never store public static WebDriver driver; when running TestNG parallel="methods" — Thread 2 closes Thread 1's browser! Keep constants public static final (like TIMEOUT_SEC = 15) and use ThreadLocal<WebDriver> for browsers.

9. Quick test

If you declare final List<String> names = new ArrayList<>();, can you call names.add("Chrome");? Yes — final only stops you writing names = new ArrayList<>();; the list contents can still change.
