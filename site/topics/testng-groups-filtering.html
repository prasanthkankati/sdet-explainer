4.2 Test Groups & Regression / Smoke Filtering

Targeted test orchestration: categorizing tests with groups, meta-groups, regular expression filtering, and Maven Surefire profiles.

Rather than running an entire 8-hour regression suite on every commit, test engineers categorize tests into logical groups such as smoke, sanity, regression, and flaky. TestNG provides first-class support for tagging and filtering test execution by groups.

1. Tagging Tests with Groups

The groups attribute on @Test accepts an array of strings. A single test can belong to multiple groups:

public class OrderCheckoutTest {
    @Test(groups = {"smoke", "checkout", "p1"})
    public void testDirectCreditCardCheckout() { ... }

    @Test(groups = {"regression", "checkout"})
    public void testGiftCardWithPromoCode() { ... }
}

2. Filtering in testng.xml

<suite name="SmokeSuite">
  <test name="FastSmoke">
    <groups>
      <run>
        <include name="smoke" />
        <exclude name="broken" />
      </run>
    </groups>
    <packages>
      <package name="com.sdet.tests.*" />
    </packages>
  </test>
</suite>

3. Senior SDET Interview Q&A

  1. What are Meta-Groups in TestNG?
    Meta-groups are groups composed of other groups defined in testng.xml. For example: <meta-group name="daily-build"><include name="smoke"/><include name="payment"/></meta-group>.
  2. How do you run specific groups from the command line without modifying XML?
    Using Maven Surefire: mvn test -Dgroups="smoke" or mvn test -Dgroups="smoke,regression" -DexcludedGroups="slow".
