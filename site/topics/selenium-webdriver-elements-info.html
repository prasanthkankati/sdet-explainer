4.3 Element Information & State

Inspecting DOM element state and properties: isDisplayed(), isEnabled(), isSelected(), getText(), getDomAttribute(), getDomProperty(), getCssValue(), and getRect().

Once a WebElement is located, test scripts frequently inspect its state, text, attributes, and computed styles to drive assertions. Selenium 4 provides boolean state checks (isDisplayed, isEnabled, isSelected) and distinguishes between initial HTML markup attributes (getDomAttribute) and live JavaScript DOM properties (getDomProperty).

Before you start

Prerequisite: 4.2 Relative Locators

Where it fits

Element information methods are called inside Page Object getter methods to return UI values back to @Test methods for TestNG/JUnit assertions.

Key points

  1. isDisplayed() returns true if the element is rendered visibly in the viewport (not display:none, visibility:hidden, or zero-sized).
  2. isEnabled() returns true unless the form control has the disabled attribute or belongs to a disabled <fieldset>.
  3. isSelected() returns true if a checkbox, radio button, or <option> element is currently checked/selected.
  4. getDomAttribute(name) reads the static initial attribute from the HTML source markup, whereas getDomProperty(name) reads the live runtime JavaScript property from the DOM object.
  5. To read the current text typed inside an <input> box, call input.getDomProperty("value") (or getAttribute("value")), because getText() only returns inner text between opening and closing tags.

How it works

  1. Locate the target WebElement using driver.findElement(By...).
  2. Invoke state methods (isDisplayed(), isEnabled(), isSelected()) to obtain boolean flags for conditional checks or assertions.
  3. Invoke getText() to extract visible, whitespace-normalized text from headings, paragraphs, labels, or buttons.
  4. Invoke getDomAttribute() for static HTML attributes (like href or class), getDomProperty("value") for live input values, and getCssValue() for computed styles.

Querying element state, DOM properties, attributes, and CSS styles:

package dev.selenium.elements; // Declares package

import org.openqa.selenium.By; // Imports By locator class
import org.openqa.selenium.Rectangle; // Imports Rectangle for geometry
import org.openqa.selenium.WebDriver; // Imports WebDriver interface
import org.openqa.selenium.WebElement; // Imports WebElement interface
import org.openqa.selenium.chrome.ChromeDriver; // Imports ChromeDriver

public class ElementInfoExample { // Declares class
    public static void main(String[] args) { // Main method
        WebDriver driver = new ChromeDriver(); // Starts Chrome session
        try { // Guarded block
            driver.get("https://www.selenium.dev/selenium/web/web-form.html"); // Loads web form
            WebElement textInput = driver.findElement(By.id("my-text-id")); // Locates text input
            textInput.sendKeys("SDET"); // Types 'SDET' into input
            System.out.println("Live value: " + textInput.getDomProperty("value")); // Prints 'SDET'
            System.out.println("HTML attr: " + textInput.getDomAttribute("type")); // Prints 'text'

            WebElement disabledInput = driver.findElement(By.name("my-disabled")); // Locates disabled input
            System.out.println("Is enabled? " + disabledInput.isEnabled()); // Prints false

            WebElement checkbox = driver.findElement(By.id("my-check-1")); // Locates checked checkbox
            System.out.println("Is selected? " + checkbox.isSelected()); // Prints true

            Rectangle rect = textInput.getRect(); // Reads x, y, width, height
            System.out.println("Width: " + rect.getWidth() + ", Color: " + textInput.getCssValue("color")); // Prints geometry and CSS color
        } finally { // Teardown block
            driver.quit(); // Closes browser
        } // Ends finally
    } // Ends main
} // Ends class

Common mistakes

  1. Calling element.getText() on an <input> field to read what the user typed, which always returns an empty string ""; fix by calling element.getDomProperty("value").
  2. Using isDisplayed() to check if an element exists in the DOM when it might not be present at all, which throws NoSuchElementException; fix by checking !driver.findElements(By...).isEmpty() first.
  3. Asserting hex colors like "#ff0000" against getCssValue("color") in Chrome, which returns computed "rgba(255, 0, 0, 1)"; fix by using Selenium's Color.fromString(el.getCssValue("color")).asHex().

Terms to know

TermMeaning
getDomAttribute()W3C method that returns only the initial attribute value declared in the HTML source markup.

getCssValue()Method that returns the browser's computed CSS style value (such as color, font-size, or display).
getRect()Method that returns a Rectangle object containing an element's x, y coordinates and width, height dimensions.

Interview questions

Basics

What are the three boolean state-checking methods on WebElement?
The three boolean methods are isDisplayed() (checks if the element is visibly rendered), isEnabled() (checks if a form element is interactive and not disabled), and isSelected() (checks if a checkbox, radio button, or option is checked).

How do you read the text currently typed inside an <input> text box?
Call inputElement.getDomProperty("value") (or getAttribute("value")). Calling getText() on an <input> returns an empty string because <input> is a void tag with no inner text.

What is the difference between getDomAttribute() and getDomProperty() in Selenium 4?
getDomAttribute() reads the static attribute written in the HTML markup (like value="initial"), whereas getDomProperty() reads the live JavaScript property in memory (which updates as the user types or checks a box).

How it works

Why was getAttribute() split into getDomAttribute() and getDomProperty() in Selenium 4?
In Selenium 3, getAttribute() executed a large JavaScript blob that guessed whether the caller wanted an HTML attribute or a JS property. The W3C standard separated them into two fast, explicit endpoints.

Does isDisplayed() return false if an element is not in the HTML DOM at all?
No. You can only call isDisplayed() on a WebElement returned by findElement(). If the element is not in the DOM, findElement() throws NoSuchElementException before isDisplayed() is ever reached.

How did getRect() replace getLocation() and getSize() in Selenium 4?
In Selenium 3, getLocation() and getSize() made two separate wire calls. In W3C Selenium 4, element.getRect() retrieves x, y, width, and height in a single HTTP command.

Real situations

How do you verify the background color of a button across Chrome and Firefox without rgba vs rgb string mismatches?
Pass the string returned by button.getCssValue("background-color") into org.openqa.selenium.support.Color.fromString(cssColor).asHex() and assert against the normalized hex code such as "#43b02a".

How do you check if a custom <button class='btn disabled'> that does not use the HTML disabled attribute is disabled?
Because isEnabled() only checks the native HTML disabled attribute, check button.getDomAttribute("class").contains("disabled") or button.getDomAttribute("aria-disabled").

What does getDomProperty("checked") return on a checkbox element?
It returns the string "true" or "false" representing the live JavaScript checked boolean property, matching what element.isSelected() returns as a Java boolean.

Troubleshooting

Why does element.getText() return an empty string even though text is present inside the HTML tag?
getText() only returns visible rendered text. If the element or its parent has CSS display: none or visibility: hidden, getText() returns "". To read hidden text, call element.getDomProperty("textContent").

Why did getDomAttribute("value") return null or the old default value after calling sendKeys("hello")?
Typing into an input modifies the live JavaScript .value property in memory, not the static HTML attribute in the DOM markup. Use getDomProperty("value") to read the updated text.

Why does isDisplayed() return true for an element covered by a modal overlay?
isDisplayed() checks whether the element has non-zero dimensions and is not hidden via CSS display/visibility; it does not check z-index occlusion. Clicking an occluded element will throw ElementClickInterceptedException.

Design choices

When should you use getDomAttribute() vs getDomProperty() in Page Objects?
Use getDomAttribute() for static markup attributes like data-testid, aria-label, or class. Use getDomProperty() for dynamic runtime state like value, checked, or selectedIndex.

Why does getText() normalize whitespace and strip leading/trailing spaces?
HTML source files often contain indentation newlines and spaces for formatting. Normalizing whitespace ensures getText() matches what a human user actually reads on the screen.

Why is Color.fromString() recommended whenever asserting on getCssValue() colors?
Browsers format computed colors differently (Chrome returns rgba(r, g, b, 1) while Firefox may return rgb(r, g, b)). Converting to .asHex() guarantees cross-browser assertion stability.

Quick answers

  1. How do you get the text typed inside an <input>? Call input.getDomProperty("value").
  2. What is the difference between getDomAttribute and getDomProperty? getDomAttribute reads static HTML markup; getDomProperty reads live JS object state.
  3. How do you read hidden text inside a display:none element? Call element.getDomProperty("textContent").
  4. How do you normalize CSS colors to hex in Selenium? Use Color.fromString(el.getCssValue("color")).asHex().
  5. Which method returns element x, y, width, and height together? element.getRect() returns a Rectangle object.
