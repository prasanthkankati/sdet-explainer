J3.3 Question Bank: Essential String Methods & Regex for SDETs (21 Questions)

Tier 1: Core Definitions, Classification & Theory (Q1–Q3)

  1. What is the difference between replace() and replaceAll() in Java?
    Both methods replace every matching occurrence across the entire string, NOT just the first occurrence. The real difference is that replace(CharSequence, CharSequence) matches exact literal text with zero regex parsing, whereas replaceAll(String regex, String replacement) compiles and matches a regular expression. When replacing literal substrings like "$" or "C:\path", always choose replace() for speed and safety.
  2. How do trim() and strip() differ?
    trim() dates back to Java 1.0 and only removes leading and trailing characters whose Unicode value is <= '\u0020' (ASCII space, tab, newline), missing Unicode whitespace like HTML non-breaking space (\u00A0). strip(), added in Java 11, uses Character.isWhitespace() to remove all Unicode whitespace characters cleanly.
  3. Explain the index arguments of "Selenium".substring(1, 4).
    The first index 1 is inclusive (character 'e') and the second index 4 is exclusive (stops before character 'n' at index 4), returning "ele" of length 4 - 1 = 3. If beginIndex > endIndex or either index is out of bounds, Java throws StringIndexOutOfBoundsException.

Tier 2: How It Works & Internal Mechanics (Q4–Q6)

  1. Why does "192.168.1.1".split(".") return an empty array of length 0?
    split() accepts a regular expression, and an unescaped dot . is a regex wildcard matching any character. Every character becomes a delimiter, producing empty strings that split(regex) trims off the trailing end by default, leaving a 0-length array. Escaping the dot inside a Java string literal as split("\\.") or split(Pattern.quote(".")) splits into 4 octets correctly.
  2. How do Pattern and Matcher extract a numeric order ID from "Order #QK-8421 confirmed"?
    Compile Pattern p = Pattern.compile("#(QK-\\d+)"); using parentheses around QK-\\d+ to form capturing group 1. Create a matcher via Matcher m = p.matcher(text); and call m.find() to scan the text for the pattern. When find() returns true, m.group(1) returns "QK-8421".
  3. Why does str.matches("\\d+") return false for "Order 123" even though digits exist?
    Unlike JavaScript's regex test or Matcher.find(), Java's String.matches(regex) implicitly wraps the pattern as if anchored with ^...$, demanding that the entire string match the pattern. To check if digits appear anywhere inside text, use Pattern.compile("\\d+").matcher(text).find().

Tier 3: Real-World SDET & Selenium Scenarios (Q7–Q9)

  1. In a Selenium test on QKart, product prices render as "₹1,499" or "$1,299.50". How do you assert numeric total math reliably?
    Extract the price text with getText(), remove everything except digits and decimal points via text.replaceAll("[^0-9.]", ""), and pass the clean string into new BigDecimal(cleanText) or Double.parseDouble(cleanText). That avoids brittle hardcoded currency symbol removals or fixed substring(1) offsets.
  2. How does String.format() help build dynamic XPath or CSS selectors inside a Page Object?
    Define a private template like private static final String PRODUCT_CARD = "//p[normalize-space()='%s']/ancestor::div[contains(@class,'card')]"; and resolve it via By.xpath(String.format(PRODUCT_CARD, productName)). Note that if productName can contain single quotes, wrap it via an XPath quote-escaping helper.
  3. How do you verify a Selenium page title or error message ignoring irregular spacing and casing?
    Normalize whitespace using actual.strip().replaceAll("\\s+", " ") and assert with equalsIgnoreCase(expected). Collapsing runs of tabs and newlines via \\s+ prevents multi-line HTML formatting differences from causing flaky failures.

Tier 4: Troubleshooting, Exceptions & Failure Modes (Q10–Q12)

  1. Why does matcher.group(1) throw IllegalStateException: No match found?
    A Matcher starts before the beginning of the input string and holds no match state until matcher.find() or matcher.matches() returns true. Calling group() unconditionally without wrapping it inside if (matcher.find()) crashes whenever the pattern misses or find() was skipped.
  2. What causes StringIndexOutOfBoundsException when using substring(text.indexOf(":") + 1)?
    If the expected delimiter ":" is missing from the UI string, indexOf(":") returns -1; adding 1 passes 0 silently or negative offsets fail when computing end indices. Always verify int idx = text.indexOf(":"); if (idx != -1) before slicing with substring().
  3. Why does "a,b,,".split(",") return length 2 instead of 4?
    The single-argument split(regex) discards trailing empty strings by default. Passing -1 as the second limit parameter ("a,b,,".split(",", -1)) preserves all trailing empty columns, which is essential when parsing CSV test data with blank trailing cells.

Tier 5: Design Choices & Rapid-Fire Recall (Q13–Q21)

  1. Why should repeated regex patterns inside a test helper or loop use a private static final Pattern field rather than String.replaceAll() or String.matches()?
    Every invocation of String.matches(), String.split() (for multi-char regex), or String.replaceAll() recompiles the regular expression state machine from scratch. Pre-compiling once via private static final Pattern ORDER_ID = Pattern.compile(...); shares the immutable compiled Pattern safely across threads with zero repeated compilation cost.
  2. When parsing HTML text in Selenium, when should you prefer XPath normalize-space() vs Java strip()?
    Use XPath normalize-space() inside locators when matching exact DOM text that has leading/trailing HTML indentation so the selector matches directly in the browser. Use Java strip() and regex on retrieved getText() values before TestNG assertions.
  3. Why should dynamic XPath templates created with String.format() sanitize inputs that contain single quotes?
    If test data includes an apostrophe like Men's Watch inside //p[text()='%s'], the unescaped quote terminates the XPath string literal prematurely and throws InvalidSelectorException. Wrapping dynamic values in an XPath concat() helper or using a parameterized By builder prevents syntax failures.
  4. What does replace() use vs replaceAll()?
    replace() matches literal characters; replaceAll() matches regular expressions.
  5. What does strip() handle that trim() misses?
    Unicode whitespace including non-breaking spaces (\u00A0).
  6. How do you split a string on a literal dot .?
    str.split("\\.") or str.split(Pattern.quote(".")).
  7. Does String.matches(regex) check partial substrings or the entire string?
    The entire string.
  8. What method must return true before calling matcher.group(1)?
    matcher.find() (or matcher.matches()).
  9. How do you preserve trailing empty fields in split(",")?
    Pass -1 as the second argument: split(",", -1).
